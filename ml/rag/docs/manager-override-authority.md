# Manager Override Authority

A manager may override any GO or NO-GO decision at their discretion.

Overrides should be reserved for context the seven model factors cannot see — for example, a customer called ahead to confirm availability despite a low `customer_history_score`, or a known local event affecting one specific address.

Every override must include a one-line reason, logged for audit and for future historical-lookup queries such as "have we overridden this before."
